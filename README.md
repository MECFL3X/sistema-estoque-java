# Sistema de Estoque em Java

Meu primeiro projeto publicado no GitHub, desenvolvido para praticar os fundamentos de Java e Programação Orientada a Objetos (POO).

O projeto consiste em um sistema simples de cadastro de produtos de informática, executado pelo console.

## Funcionalidades

- Cadastro de produtos com nome, categoria, marca, preço e quantidade.
- Seleção de categorias por meio de um menu.
- Geração automática de códigos para os produtos.
- Numeração sequencial por categoria.
- Armazenamento dos produtos em uma lista (`ArrayList`).
- Exibição dos produtos cadastrados no console.
- Métodos para adicionar e remover unidades do estoque.

## Conceitos utilizados

- Java
- Programação Orientada a Objetos (POO)
- Classes, objetos e construtores
- Encapsulamento
- Métodos e atributos
- Estruturas de repetição e condicionais
- Listas com `ArrayList`
- Entrada de dados com `Scanner`

## Como executar

1. Baixe ou clone este repositório.
2. Importe o projeto em uma IDE Java, como o Eclipse.
3. Execute a classe `Informatica.java`, localizada no pacote `aplication`.
4. Siga as instruções exibidas no console.

## Sobre o projeto

Este projeto faz parte dos meus estudos em desenvolvimento Java.

Ainda está em desenvolvimento e será atualizado conforme eu aprender novos conceitos e implementar outras funcionalidades.
